
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Criar uma versão em Python do clássico jogo da Forca para praticar manipulação de strings, loops, condicionais e seleção aleatória.

## 📝 Tarefas

### 🛠️	Implementar o Jogo da Forca

#### Descrição
Desenvolva um programa em Python em que o jogador tenta adivinhar uma palavra secreta, letra por letra, antes de acabar o número de tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida
- Aceitar palpites de letras e mostrar o progresso atual da palavra (ex.: `_ _ _ _`)
- Rastrear e exibir o número de tentativas incorretas restantes
- Encerrar o jogo quando a palavra for adivinhada ou quando as tentativas acabarem
- Exibir mensagens claras de vitória e derrota
